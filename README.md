# Humphrey Bot
## A Bot Butler for Discord

This is my Discord Bot project. He's a friendly butler who can do a rather large amount of things, including search the web, the wiki, YT, grab an image, quote members of the chat, grab stuff from other channels, and a lot of commands kind of unique to my server, like letting people pick their colour-role or !moo. 

I'm posting him publicly for there to be some kind of evidence that I can code, and in case anyone is interested in him. He is in desperate need of an OOP refactor to utilize Cogs.
